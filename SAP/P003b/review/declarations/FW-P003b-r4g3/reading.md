## Shared mathematical expansion

These expansions are used in each section below, so that the notation in the five readings has no remaining SAP-defined primitives.

* A count vector is an arbitrary quadruple `(a,b,c,d)` of natural numbers. For a potential-outcome vector these count types `(11,10,01,00)`; an observed vector instead counts `(treated success, treated failure, control success, control failure)`. Write `N(v)=a+b+c+d`, `e(v)=b-c` in the integers, and `tau(v)=(b-c)/N(v)` in the rationals, embedded in the reals when necessary. The observed estimate is `a/(a+b)-c/(c+d)`.
* Given observed `o`, possible vectors are exactly the entries of the finite list obtained by letting `0<=i<=o.a`, `0<=j<=o.b`, `0<=k<=o.c`, `0<=l<=o.d`, and forming `(i+k,o.a-i+l,o.c-k+j,o.b+o.d-j-l)`. Membership is what `Possible` means. This enumerates imputed potential outcomes. Repeated entries are possible; conversion to a finite set removes duplicates.
* For population `v` and treatment size `m`, the random-state list consists of `(a,b,c,d)` with `a<=min(v.a,m)`, `b<=min(v.b,m-a)`, `c<=min(v.c,m-a-b)`, `d=m-a-b-c<=v.d`. Its weight is `w_v(q)=choose(v.a,q.a) choose(v.b,q.b) choose(v.c,q.c) choose(v.d,q.d)`. Here `choose` is `Nat.fast_choose`. The observation from state `q` is `(q.a+q.b,q.c+q.d,v.a-q.a+v.c-q.c,v.b-q.b+v.d-q.d)`.
* Put `A(v,o,m)=N(v)((N(v)-m)o.a-m o.c)-m(N(v)-m)e(v)`, with all arithmetic in this formula integral. The exact p-value is the rational sum of `w_v(q)` over random states at `m=o.a+o.b` satisfying `|A(v,observed(v,q),m)|>=|A(v,o,m)|`, divided by `choose(N(v),m)`. Rational acceptance is the same weak inequality `alpha<=p` implemented by clearing the positive rational denominator; its separate zero-binomial branch returns `alpha<=0`.
* The real finite accepted set is `{tau(v) : v possible for o and alpha<=p(v,o)}`. The exact interval is its interval hull: `t` belongs precisely when there are two members `l,u` with `l<=t<=u`. Its endpoints are the real infimum and supremum of the finite set. Rational `intervalQ` is `none` if there are no accepted vectors, otherwise `some(min e/N(o),max e/N(o))`.
* Candidate effect numerators are the list `o.a-o.c-(o.a+o.b)+k`, `k=0,...,N(o)`, using integer casts. For an integer `x` and natural `j`, the line group is the possible-vector list restricted by `e(v)=x` and `v.a+v.b=j`. Its selector is `none` on an empty list and otherwise a vector with smallest `b` (earlier entries win ties). The query candidate list concatenates this selector for every `j=0,...,N(o)`. When a selected vector has `b=c=0`, `a,d>=1`, and `(a-1,1,1,d-1)` is possible, it appends that second vector immediately after the first.
* A test oracle has type `Counts -> natural index -> Bool`, where `true` means reject. Testing a candidate list proceeds in order, increments the test index for every performed test, stops at the first acceptance, and reports compatible exactly when it accepted a vector. The trace is the chronological list of `(vector,rejected?)`. An empty candidate list is incompatible with no tests.
* The upper search sets `k1=2(o.a-o.c)` and `k2=o.a-o.c+(o.a+o.b)`, and starts with index 0 unless another start is supplied. Its fuel is `N(o)+3`. The corrected version starts at `(k1-1,k2+1)` and immediately returns the left endpoint when `b<=a+1`. Otherwise it tests the candidate query at the integer midpoint `(a+b)/2`; compatibility replaces `a` by the midpoint, incompatibility replaces `b`; then it recurses. Exhausted fuel returns `none`. The uncorrected version starts at `(k1,k2)`, tests before checking adjacency, and, at adjacency, returns the left endpoint for an interior bracket; if the left endpoint is `k1` it performs an additional `k1` query and returns `k1` or `k1-1`; otherwise if the right endpoint is `k2` it queries `k2` and returns `k2` or `k2-1`. An unmatched boundary branch returns `none`. All recursive traces are concatenated.
* Complementing observed outcomes means `(a,b,c,d)->(b,a,d,c)`. The exact upper oracle rejects iff `p<alpha`. A labeled table is a function `Fin n -> Bool x Bool`. An assignment is a finite subset of `Fin n` with cardinality `m`. The canonical labeled table consists of successive blocks of lengths `v.a,v.b,v.c,v.d`, carrying types `11,10,01,00`. Its observation counts treated first coordinates and untreated second coordinates. `w1Observed` counts these for an arbitrary labeled table instead.
* Put `D(n)=(n+1)(Nat.log2(n+1)+3)` and `log2(x)=Real.log(x)/Real.log(2)`. A pool is a function from `Fin(2D(n)+1)` to `Fin K` to assignments. Batch `idx` uses the coordinate `idx modulo (2D(n)+1)`. The Monte Carlo mean is the rational mean of the same tail indicator defining `p`, evaluated at the canonical observations for the K assignments. Approximate rejection is `mean+epsilon<alpha`. Compute the corrected upper endpoint first, then the complemented endpoint starting at the number of upper tests. When both return integers `lo,hi`, the Monte Carlo interval is `[-lo/N(o),hi/N(o)]`; otherwise it is empty.
* `uniformProb(E)` on a finite type Omega is the real ratio `#{omega:E(omega)}/#Omega`. It is the uniform law on the entire finite product/function space, so pool coordinates and all K assignment coordinates are independent. The joint Monte Carlo space adds an independent observed assignment to the pool.
