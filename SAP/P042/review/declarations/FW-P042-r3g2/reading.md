### Basic objects and fully expanded notation

For a natural number N, let I = Fin N, the finite set of natural indices less
than N. All sums over i below are over I. Booleans false and true label the
two states. All outcome values, averages, differences, and quotients are real.
Natural cardinalities and sizes in real formulas are cast to real numbers.
Write N dotminus m for truncated natural subtraction, before casting.

For any finite set s and real function f on its underlying type, write
E_s f = (sum over x in s of f(x)) / |s|. This is the exact definition of
`finiteExpectation`, not a probabilistic hypothesis. Define
C(N,m) = {S subset I : |S| = m}; this is
`completeAssignments`, implemented as the m-element subsets of Finset.univ.
Write P(U) = (sum_i U(i))/N (`populationMean`),
T_m(S,U) = (sum_i 1_{i in S} U(i))/m (`assignedTreatmentMean`), and
K_m(S,U) = (sum_i 1_{i not in S} U(i))/(N dotminus m)
(`assignedControlMean`). Here indicator notation means U(i) or zero as
selected by an if-expression, so there is no unspecified value.

For a schedule Y : I -> Bool -> real, the observed assignment outcome is
O(S,Y)(i) = Y(i,true) if i in S, and Y(i,false) otherwise
(`assignedOutcome`). For c : I -> Bool, define
C_c = {i : c(i)=true}, n_c = |C_c| (`complierCount`),
pi_c = n_c/N (`complierShare`), and
tau_c(Y) = (sum_{i in C_c} (Y(i,true)-Y(i,false)))/n_c
(`complierEffect`). The assignment effect with one-sided contact is
A(Y,c) = (sum_i (Y(i,c(i))-Y(i,false)))/N (`assignmentEffect`).
The observed contact outcome is
H(S,Y,c)(i) = Y(i,c(i)) if i in S, and Y(i,false) otherwise
(`contactedOutcome`). Thus c determines which assigned subjects can receive
contact; controls never receive contact, and only own contact determines
the selected potential outcome. The assigned contact rate is
F_m(S,c) = (sum_i 1_{i in S and c(i)=true})/m (`assignedContactRate`).

On a measurable space Omega with measure mu, define
p_mu(B) = (mu(B)).toReal (`eventProbabilityW2`), and
M_mu(X,B) = (integral over B of X with respect to mu)/p_mu(B)
(`eventMeanW2`). The integral is Mathlib's real Bochner integral with
the restricted measure mu.restrict B. The theorem uses these as ordinary
conditional means on positive-probability events under a probability
measure. `IndepFun f g mu` is Mathlib independence of the sigma algebras
generated by f and g; equivalently, for the measurable maps here, every
pair of measurable target events has preimage intersection probability
equal to the product of the two preimage probabilities.

### 1. Finite complete-randomization identities and arithmetic

First, for every N,m : natural, assuming 2 <= N, 1 <= m, and
m <= N dotminus 1, for every schedule Y : I -> Bool -> real, all of the
following hold:

* For every t : Bool, E_C T_m(S, i -> Y(i,t)) = P(i -> Y(i,t)) and
  E_C K_m(S, i -> Y(i,t)) = P(i -> Y(i,t)), where C = C(N,m).
* E_C [T_m(S,O(S,Y))-K_m(S,O(S,Y))]
  = (sum_i (Y(i,true)-Y(i,false)))/N.
* For every c : I -> Bool, assuming 0 < n_c, let
  d(S) = T_m(S,H(S,Y,c))-K_m(S,H(S,Y,c)). Then
  A(Y,c) = pi_c * tau_c(Y),
  E_C d = A(Y,c), E_C F_m(S,c) = pi_c,
  0 < E_C F_m(S,c), and
  tau_c(Y) = (E_C d)/(E_C F_m(S,c)).

Second, the real arithmetic equality
((94/10 - 70/10)/(1/2)) = 48/10 holds. This supplies the numerical
illustration 9.4 minus 7.0 percentage points, divided by 0.50, equals 4.8
percentage points. This entire first proposition is `T6Statement`.

Uniform assignment is represented by exact averaging over all m-subsets,
not by any unspecified probability law. No outcome-range assumptions or
random superpopulation are imposed on these fixed schedules. In the
first two identities Y is a schedule indexed by assignment state; in the
contact identities Y is a schedule indexed by own contact state.

### 2. Population balance under independent assignment

For every Omega : Type, every measurable-space structure on Omega,
every measure mu and instance that mu is a probability measure, and every
Z : Omega -> Bool: assuming Z is measurable and
for every z : Bool, p_mu({omega : Z(omega)=z}) > 0,
for every Y : Omega -> Bool -> real, assume each section Y_t is measurable,
each Y_t is integrable with respect to mu, and Z is independent of
omega -> (Y(omega,false),Y(omega,true)). Then

* for every t,z : Bool,
  M_mu(Y_t,{Z=z}) = integral Y_t dmu;
* M_mu(omega -> Y(omega,Z(omega)),{Z=true})
  - M_mu(omega -> Y(omega,Z(omega)),{Z=false})
  = integral (Y_true - Y_false) dmu.

This is `RandomizedBalanceW2`. There is no restriction to equal arm
probabilities, atomless spaces, or finite spaces.

### 3. Population one-sided contact identities

For every Omega : Type with a measurable-space structure, every measure mu
with a probability-measure instance, and every pair Z,c : Omega -> Bool,
assume both maps measurable, p_mu({Z=z}) > 0 for each z : Bool, and
p_mu({c=true}) > 0. For every schedule Y : Omega -> Bool -> real, assume
each section is measurable and integrable, and Z is independent of the
joint random object omega -> (c(omega),(Y(omega,false),Y(omega,true))).

Set pi = p_mu({c=true}),
CACE = M_mu(Y_true-Y_false,{c=true}),
ITT = integral (omega -> Y(omega,c(omega))-Y(omega,false)) dmu,
H(omega) = Y(omega,Z(omega) && c(omega))
(`randomContactOutcomeW2`, with Boolean conjunction),
Delta = M_mu(H,{Z=true})-M_mu(H,{Z=false}), and
F(omega) = 1 if Z(omega) && c(omega), and 0 otherwise.
The conclusions, in order, are
ITT = pi*CACE, Delta = ITT,
M_mu(F,{Z=true}) = pi, M_mu(F,{Z=false}) = 0, and
CACE = Delta/M_mu(F,{Z=true}).

This is `RandomizedContactW2`. One-sided receipt, exclusion, and own-unit
outcomes are built into H; arbitrary assignment effects separate from
contact or effects from other subjects' contacts are not represented.
Independence includes compliance type as well as both potential outcomes.

### 4. Independence for a uniformly sampled subject

For every N,m : natural with 2 <= N, 1 <= m, and m <= N dotminus 1,
for every type A, map v : I -> A, set B subset A, and Boolean b,

(1/N) sum_i [(1/|C(N,m)|) sum_{S in C(N,m)}
  1_{(decide(i in S)=b) and (v(i) in B)}]
= q_b * (1/N) sum_i 1_{v(i) in B},

where q_true = m/N and q_false = 1-m/N. This is
`SampledSubjectIndependenceW2`. The left side averages independently over
a uniform subject and uniform complete assignment; the right side is
the product of their treatment-state probability and attribute-event
probability. A need not have a measurable-space structure: the finite
empirical distributions make any attribute event meaningful.

### 5. Binary never-taker nonidentification

For every N : natural, Y : I -> Bool -> real, c : I -> Bool, and
k : I, assume (for every i,t, Y(i,t)=0 or Y(i,t)=1)
(`BinaryScheduleW2`) and c(k)=false. There exists a schedule
Y' : I -> Bool -> real such that:

* every Y'(i,t) is zero or one;
* for every finite subset S of I, H(S,Y',c) = H(S,Y,c), as functions on I;
* for every i,t, if i != k or t=false, then Y'(i,t)=Y(i,t);
* Y'(k,true)-Y'(k,false) != Y(k,true)-Y(k,false);
* 0 < n_n, where n_n = |{i : c(i)=false}| (`neverTakerCountW2`);
* (sum_{i:c(i)=false}(Y'(i,true)-Y'(i,false)))/n_n
  != (sum_{i:c(i)=false}(Y(i,true)-Y(i,false)))/n_n
  (the two `neverTakerEffectW2` values).

This is `NeverTakerNonidentificationW2`. N is not explicitly lower
bounded; the supplied k : Fin N guarantees N >= 1 and witnesses n_n > 0.
The comparison is stronger than equality of observed distributions:
observed outcome vectors coincide for every assignment, even outside a
particular fixed-size design. The only allowed schedule change is the
unobserved contact outcome of k. No positive Complier count is required
for this separately quantified nonidentification proposition.

### 6. Realized estimator formula

Define R_m(S,Y,c) =
[T_m(S,H(S,Y,c))-K_m(S,H(S,Y,c))]/F_m(S,c)
(`contactEstimatorW2`). For every N,m : natural with
2 <= N, 1 <= m, and m <= N dotminus 1, every
Y : I -> Bool -> real, c : I -> Bool, and S : Finset I,
assume S in C(N,m) and 0 < F_m(S,c). Then
R_m(S,Y,c) equals the quotient defining it, and
R_m(S,Y,c)*F_m(S,c) = T_m(S,H(S,Y,c))-K_m(S,H(S,Y,c)).
This is `RealizedEstimatorFormulaW2`. It states the definition and valid
denominator cancellation. It asserts no expectation of R, limiting
property, accuracy guarantee, or unbiasedness of the realized quotient.
